# Target Roles — Gustavo Calderón Tenorio

## Posicionamiento actual
AI-Augmented Developer en transición hacia Data Engineering.

---

## Objetivo principal (corto plazo)
Conseguir primeras oportunidades en tecnología a través de:
- Freelance
- Roles junior
- Proyectos reales

---

## Roles objetivo principales

### 1. AI-Augmented Developer
Perfil que utiliza herramientas de IA para acelerar desarrollo, iteración y entrega de productos web.

### 2. Junior Full-Stack Developer
Desarrollo de aplicaciones web completas con frontend y backend, integrando APIs y desplegando en producción.

### 3. Frontend Developer
Construcción de interfaces modernas, responsive y enfocadas en experiencia de usuario.

### 4. Freelance Web Developer
Desarrollo de proyectos web para clientes, incluyendo landing pages, apps simples y soluciones personalizadas.

- Junior AI/Product Developer
- Automation Developer (con IA)

## Objetivo profesional a mediano / largo plazo

Evolucionar progresivamente hacia roles más avanzados en inteligencia artificial, incluyendo:

- Data Engineer
- AI Engineer
- Generative AI Engineer

Estos roles forman parte de la formación actual en la academia Zero to Mastery (ZTM) y representan la dirección profesional futura, no el posicionamiento actual en el mercado laboral.
